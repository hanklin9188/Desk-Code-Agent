# Motion Storyboard

## Scene 1 — Repository acquisition

1. Repository card locks to baseline SHA.
2. Index stage appears; counts crossfade at ≤4Hz.
3. Sidebar tree becomes interactive as soon as first index segment is available.
4. Final index status settles; no celebratory effect.

## Scene 2 — Analysis

1. Orchestrator moves queued→active.
2. Dispatch event highlights Repo Analyst and edge.
3. Tool events travel Agent→RepoIntelligence; evidence counter increments.
4. Architecture graph appears only after graph artifact, with one layout transition.
5. Findings stream as stable cards; no reorder animation after user starts reading.

## Scene 3 — Coding

1. Feasibility result opens as compact scope summary.
2. Coder becomes active; current Skill badge changes R17→R18→R19→R20.
3. Patch-created event adds Diff badge but does not steal focus.
4. Verification stages activate in sequence from machine events.
5. Failed test performs one restrained nudge; retry edge displays failure ID.

## Scene 4 — Review and approval

1. Spec and Standards lanes activate sequentially while visually distinct.
2. Approval only appears after both axes and required verification are complete.
3. Management Bar enters 12px + fade; buttons are immediately interactive.
4. Deny exits without guilt animation; approve records action and shows remote progress.

## Scene 5 — Reduced motion

All travel, scale and layout transitions are replaced by immediate state labels and short opacity/background changes. The user receives identical information and action timing.
