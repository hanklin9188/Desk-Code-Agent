# New or Changed Skill Checklist

- [ ] Use D09.
- [ ] Distinct trigger branch justifies a Skill.
- [ ] Invocation user/model/runtime chosen intentionally.
- [ ] Inputs/outputs are versioned artifacts.
- [ ] Tool surface is minimal and deny-by-default.
- [ ] Legal states/edges registered.
- [ ] LLM/context/retry/wall-time/side-effect budgets.
- [ ] Every step has completion criterion.
- [ ] Untrusted content and permission behavior.
- [ ] Unit/boundary/failure/adversarial/cancel/stale fixtures.
- [ ] Paired baseline and promotion criteria pre-registered.
- [ ] Source/license/adaptation note.
- [ ] Compatibility/changelog/migration.
- [ ] Production router feature flag remains off until gate.
