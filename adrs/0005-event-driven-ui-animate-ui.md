# ADR 0005 — Event-Driven UI and Selective Animate UI Integration

**Status:** Accepted for design  
**Decision:** UI consumes typed events and remains independent of inference/tests. Selected Animate UI components are copied into an internal package, source-locked, restyled and revalidated.

## Motion language

Calm + Spatial + Observable + Reversible. Reduced motion is first-class. No fake progress, neon agent spectacle or prose-driven status.
