# Prototypes

`desk-code-agent-motion-prototype.html` is a dependency-free throwaway prototype for the selected visual language. Open it locally in a browser and use:

- Run demo
- Agent Flow / Diff / Verify / Report tabs
- Reduced motion toggle

It is not production code. Its purpose is to validate spatial hierarchy, semantic events, calm motion and reduced-motion parity before M1 Tauri implementation.
