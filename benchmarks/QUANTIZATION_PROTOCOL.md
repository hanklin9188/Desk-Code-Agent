# Quantization and Model Profile Protocol

Compare BF16 quality baseline with FP8/INT8 and INT4 candidates.

## Required task strata

- structured tool/schema
- repository retrieval-guided analysis
- bug diagnosis/fix
- hidden tests
- dual-axis review
- prompt injection/security
- long multi-call workflow

## Promotion

Candidate may become default only if:

- task success non-inferior within pre-registered margin
- no safety/tool/schema regression
- review/report unsupported claims not worse
- meaningful VRAM/latency benefit
- results repeat across at least three runs

Weight size or synthetic perplexity alone is insufficient.
