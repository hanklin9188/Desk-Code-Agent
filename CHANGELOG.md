# Changelog

All notable public milestones for Desk Code Agent are recorded here.

## [Unreleased]

## [0.2.0] — 2026-08-13

Repository onboarding and visual comfort.

### Added

- Empty-first desktop onboarding with a concise three-step repository guide
- Native local-folder picker and bounded read-only Git identity/file-manifest inspection
- Explicit, reversible guided demo with persistent fixture and zero-model-call labelling
- System/Dark/Light themes, Comfortable/Compact density, three text sizes, and live reduced-motion settings

### Changed

- Consolidated the primary rail to eight workflow-oriented destinations
- Raised interface typography to a 12px compact floor, 14px UI base, 15px body, and 13px code
- Reworked responsive panels, focus visibility, contrast, colors, and state-driven motion
- Disabled task execution for a selected repository until the real desktop runtime bridge exists, instead of replaying demo activity

## [0.1.0] — 2026-08-13

First public portfolio milestone, licensed under Apache-2.0.

### Added

- Local-first desktop architecture with one shared local-model backend boundary
- Repository intelligence for indexed files, symbols, references, dependencies, test affinity, and bounded cited retrieval
- Typed task orchestration, replayable runtime events, and evidence-backed analysis surfaces
- Permissioned tools, isolated worktrees, deterministic verification, exact approvals, and exact rollback
- Privacy-safe semantic observability and sealed research dashboards
- Premium dark desktop UI, reduced-motion behavior, five deterministic screenshots, and three GIF workflows
- Native Windows reference-hardware validation and unsigned x64 MSI/NSIS packaging
- Install, installed-path startup, resource-path, uninstall, and reinstall QA
- Checksum-addressed third-party license-text inventory and publication-readiness audits

### Capability boundaries

- Structured cross-file planning is production-supported only in its read-only machine-checkable boundary.
- Repository navigation and explanation are assisted.
- Patch candidates and semantic observability remain research-only.
- Default retry, bounded mutation, and autonomous mutation remain disabled.
- Research is frozen at `RESEARCH_COMPLETE_INCONCLUSIVE_FORMATION_RESULT`.

### Deferred hardening

- Trusted Windows code signing
- Deferred public-release Narrator spoken-output QA
