# G2 ceiling classification

Status: final classification carried into G3; G2 artifacts are immutable.

The sealed G2 run produced 210/210 end-to-end task successes for E1, 210/210 for E-MIN-V2, and 210/210 for E-MIN-V3. There was no pairwise task-success discrimination. The answer-option format also created option-cue and answer-shape shortcut risk, even though deterministic pipeline, safety, seal, and reproducibility checks remained valid.

G2 is therefore retained for regression detection, deterministic pipeline validation, safety validation, and reproducibility. It is not sufficient for ranking high-performing harness variants, establishing superiority, or making strong real-world generalization claims. No G3 task, threshold, retrieval rule, or production decision was tuned against G2.

The production state entering G3 remained E-MIN-V2 default, E-MIN-V3 frozen research candidate, global Multi-Agent disabled, semantic reviewer disabled by default, and deterministic safety/verification enabled.
