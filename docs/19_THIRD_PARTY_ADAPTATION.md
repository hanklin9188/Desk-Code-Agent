# Third-Party Adaptation

The project uses an explicit provenance pipeline:

```text
External source
→ license and revision review
→ principle extraction
→ original bounded design
→ static validation
→ paired evaluation
→ production candidate
```

No third-party Skill is enabled merely because it is popular. No copied Animate UI component enters production without source lock, license notice, Desk tokens, accessibility and performance review.
