# Desk Code Agent v0.2.0 presentation media

This directory contains the current README and social-preview presentation set for `v0.2.0 — Repository onboarding and visual comfort`.

All five screenshots come from the isolated `?presentation=` registry in `apps/desktop/src/app/presentationMode.ts`. That registry uses reduced motion, synchronous product state, a sanitized repository fixture, zero model calls, and zero benchmark calls. It never opens a native picker or reads a real repository.

The historical v0.1.0 media under `docs/media/screenshots`, `docs/media/gifs`, and `docs/media/CAPTURE_MANIFEST.json` remains immutable and is not superseded as historical evidence. This versioned package is the public presentation source for the redesigned UI.

The social-preview PNG is ready locally. GitHub repository social previews can only be changed through the repository Settings web UI in the available toolchain; local readiness does not claim that the upload occurred.
