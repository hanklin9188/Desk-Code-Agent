# Milestone Gates

Every M0–M10 milestone requires:

1. Scope/spec approved.
2. Code/docs/schemas updated.
3. Static/unit/integration/adversarial checks pass.
4. Relevant Skill paired evaluation passes or is marked experimental.
5. Security/license/secret scans pass.
6. UI change has keyboard/reduced-motion/performance evidence.
7. Reproduction commands and hashes generated.
8. D07 review has no blocker.
9. D11 handoff prepared.
10. With explicit approval, branch/draft PR/CI checkpoint on `hanklin91888/Desk-Code-Agent`.

No GitHub checkpoint means the milestone is locally complete, not delivered.
